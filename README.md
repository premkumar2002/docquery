# DocuQuery
DocuQuery is a powerful tool for querying and managing documents with ease.

## Architecture

- **Backend**: Python-based API for document processing and querying.
- **Frontend**: React.js application for an intuitive user interface.
- **Infrastructure**: Hosted on AWS with S3 for storage and Lambda for serverless execution.

## Tech Stack

- Python
- React.js
- AWS (S3, Lambda)
- PostgreSQL
- Docker
